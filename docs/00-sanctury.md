# VSCode

El motivo por el que elegi visual studio code es por que es un ediotor de codigo con amplia variedad de extenciones, lo cual me ayuda a configurar todo desde
un mismo entorno si necesidad de estar cambiando entre un ide y un editor de codigo, con su rendimiento ligero ayuda a que el proceso sea mas rapido y con la gran variedad de plugin me
ayuda a manejar los _git action_ y _sqllite_ en el mismo lugar ahorrando tiempo y facilitando mi proceso de desarrollo.
Pycharm a pesar de ser un IDE especial para python y tener caracteristicas avanzadas que podrian ayudar al desarrollo a mi punto de vista el costo beneficio no supera los beneficios que me vs, tambien la comodidad de poder configurar tu entorno para sentirte mas comodo al trabajar es una ventaja silecionsa que hace que me sienta mas comodo y cursos no
tiene tantas extenciones como las tiene vs code.
